Predicting next season's summer crop

Python · pandas · XGBoost · scikit-learn  |  Download the notebook (.ipynb)  ·  GitHub repo

Can a field's records from last season predict what the grower will plant this season? Crop rotation is highly patterned (corn after soybeans, soybeans after corn), but plenty of fields break the pattern. Knowing the likely crop ahead of time helps with seed and fertilizer planning, sales forecasting, and filling gaps in field records.

This notebook trains a gradient-boosted classifier (XGBoost) on one-year-lagged field features and compares it against a simple rotation rule.

About the data. I built the original version of this model at work, in PySpark on Databricks, using real field management records. Those data are proprietary, so this public version uses simulated fields with generic column names. The simulation mimics the real structure: common rotations, continuous corn, corn-soybean-wheat rotations, cover crops, missing values, and fields with gaps in their history. The modeling steps are the same. The numbers are not real results.

1. Simulated field records

Each row is one field in one season (2016-2024), across six Corn Belt and Plains states. Every field gets a rotation habit, and roughly 8% of seasons deviate from it at random. Fields that will go to winter wheat usually have it seeded in the fall of the prior season, which shows up in winter_crop. Cover-crop adopters favor cereal rye ahead of soybeans and oats or radish ahead of corn. About 4% of field-seasons are missing entirely, to mimic gaps in real records.

Show the data simulation code
def simulate_fields(n_fields=3000, years=range(2016, 2025), seed=42):
    rng = np.random.default_rng(seed)
    years = list(years)
    states = ["IA", "IL", "MN", "NE", "KS", "IN"]
    habits = ["corn-soy", "continuous corn", "corn-soy-wheat", "continuous soy", "flexible"]
    habit_p = {s: [0.55, 0.12, 0.15, 0.05, 0.13] for s in states}
    habit_p["KS"] = [0.30, 0.10, 0.40, 0.05, 0.15]
    habit_p["MN"] = [0.50, 0.10, 0.22, 0.05, 0.13]
    cycles = {"corn-soy": ["Corn", "Soybeans"], "continuous corn": ["Corn"],
              "corn-soy-wheat": ["Corn", "Soybeans", "Wheat"], "continuous soy": ["Soybeans"]}
    weather = {(s, y): (rng.normal(780, 120), rng.normal(18.5, 1.2)) for s in states for y in years}

    rows = []
    for f in range(n_fields):
        state = rng.choice(states)
        county = f"{state}-{rng.integers(1, 13):02d}"
        habit = rng.choice(habits, p=habit_p[state])
        phase = rng.integers(0, 6)                    # 6 = lcm of cycle lengths 2 and 3
        cover_adopter = rng.random() < 0.25
        crops = []
        for i, y in enumerate(years):
            if habit == "flexible":
                crop = rng.choice(["Corn", "Soybeans", "Wheat"], p=[0.5, 0.42, 0.08])
            else:
                cyc = cycles[habit]
                crop = cyc[(i + phase) % len(cyc)]
            if rng.random() < 0.08:                      # break from habit
                crop = rng.choice([c for c in ["Corn", "Soybeans", "Wheat"] if c != crop], p=[0.8, 0.2])
            if rng.random() < 0.004:                     # rare crops
                crop = rng.choice(["Sorghum", "Sunflower"])
            crops.append(crop)

        for i, y in enumerate(years):
            crop = crops[i]
            nxt = crops[i + 1] if i + 1 < len(crops) else None
            wheat_label = "Spring Wheat" if state == "MN" else "Winter Wheat"
            winter = "Wheat" if nxt == "Wheat" and wheat_label == "Winter Wheat" and rng.random() < 0.85 else "None"
            cover = "None"
            if winter == "None" and cover_adopter and rng.random() < 0.7:
                if nxt == "Soybeans":
                    cover = rng.choice(["Cereal Rye", "Oats", "Radish Mix"], p=[0.7, 0.2, 0.1])
                else:
                    cover = rng.choice(["Cereal Rye", "Oats", "Radish Mix"], p=[0.2, 0.45, 0.35])
            precip, temp = weather[(state, y)]
            base_yield = {"Corn": 190, "Soybeans": 58, "Wheat": 70}.get(crop, 80)
            if crop == "Corn" and i > 0 and crops[i - 1] == "Corn":
                base_yield -= 12                         # continuous-corn yield drag
            rows.append({
                "field_id": f"F{f:05d}",
                "year": y,
                "state": state,
                "county": county,
                "crop": wheat_label if crop == "Wheat" else crop,
                "winter_crop": winter,
                "cover_crop_type": cover,
                "fert_passes": {"Corn": rng.integers(2, 4), "Soybeans": rng.integers(0, 2),
                                "Wheat": rng.integers(1, 3)}.get(crop, 1),
                "used_stabilizer": bool(crop == "Corn" and rng.random() < 0.4),
                "planting_doy": {"Corn": 120, "Soybeans": 135, "Wheat": 110 if state == "MN" else 280}.get(crop, 140)
                                + rng.normal(0, 8),
                "precip_mm": precip + rng.normal(0, 40),
                "temp_c": temp + rng.normal(0, 0.4),
                "yield_bu_ac": base_yield * rng.normal(1, 0.12),
            })

    df = pd.DataFrame(rows)
    df = df.sample(frac=0.96, random_state=seed).sort_values(["field_id", "year"]).reset_index(drop=True)
    for i, col in enumerate(["planting_doy", "precip_mm", "temp_c", "cover_crop_type"]):  # sprinkle in missing values
        df.loc[df.sample(frac=0.03, random_state=seed + i).index, col] = np.nan
    return df.round({"planting_doy": 0, "precip_mm": 0, "temp_c": 1, "yield_bu_ac": 1})

2. Clean up

Three steps, matching the original pipeline:

  1. Collapse wheat varieties into a single Wheat class.
  2. Drop crops with 10 or fewer fields in any year. There's too little data to learn them.
  3. Fill missing numbers with the median and missing categories with the most common value.
df = raw.copy()
df["crop"] = df["crop"].str.replace(r".*Wheat.*", "Wheat", regex=True)

3. One-year lag features

For each field, attach last season's records to this season's crop. One fix over my first version: a plain shift() (or Spark's lag()) grabs the previous row. If a field skipped a year, "last season" is really two seasons ago. So I keep only rows where the previous record is from exactly the prior year.

lag_cols = ["crop", "winter_crop", "cover_crop_type", "fert_passes", "used_stabilizer",
            "planting_doy", "precip_mm", "temp_c", "yield_bu_ac"]

df = df.sort_values(["field_id", "year"])
prev = df.groupby("field_id")[["year"] + lag_cols].shift(1).add_prefix("prev_")
lagged = pd.concat([df[["field_id", "year", "state", "county", "crop"]], prev], axis=1)

has_prev = lagged["prev_year"].notna()
consecutive = lagged["prev_year"] == lagged["year"] - 1
print(f"Rows with any earlier record:       {has_prev.sum():,}")
print(f"...where it is really the prior year: {consecutive.sum():,}  "

4. Train / validation / test split by year

The split is by time, not random rows, so the model is always predicting a season it hasn't seen.

Split Seasons

Validation (early stopping) 2023

year itself is not a feature. The test year never appears in training, so it can only add noise. Categorical columns use XGBoost's native categorical support. Index-encoding them as numbers would imply a false order, such as county 11 being "near" county 12.

features = ["state", "county", "prev_crop", "prev_winter_crop", "prev_cover_crop_type",

5. Baseline: the rotation rule

Corn → soybeans, soybeans → corn, wheat → corn. If the model can't beat this rule, it isn't worth running.

rotation = {"Corn": "Soybeans", "Soybeans": "Corn", "Wheat": "Corn"}
baseline_pred = model_df.loc[test, "prev_crop"].map(rotation)
y_test_labels = model_df.loc[test, "crop"]

Most remaining errors are fields that break their usual pattern, like continuous corn or a one-off switch. One season of history can't tell "corn after corn on purpose" from "corn after corn by accident".

9. Next step: two seasons of history

Adding the crop from two seasons back (again requiring consecutive years) lets the model recognize continuous corn and three-year rotations.

prev2 = df.groupby("field_id")[["year", "crop"]].shift(2).add_prefix("prev2_")
two = pd.concat([lagged, prev2], axis=1)
two = two[(two.prev_year == two.year - 1) & (two.prev2_year == two.year - 2)].reset_index(drop=True)

X2 = two[features + ["prev2_crop"]].copy()
X2["prev_used_stabilizer"] = X2["prev_used_stabilizer"].astype(bool).astype(int)
for c in cat_features + ["prev2_crop"]:
    X2[c] = X2[c].astype("category")
y2 = two["crop"].map({c: i for i, c in enumerate(classes)})
tr2, va2, te2 = two.year <= 2022, two.year == 2023, two.year == 2024

model2 = XGBClassifier(**{**model.get_params(), "random_state": 42})
model2.fit(X2[tr2], y2[tr2], eval_set=[(X2[va2], y2[va2])], verbose=False)
pred2 = pd.Series(model2.predict(X2[te2])).map(dict(enumerate(classes)))

results.loc["XGBoost (2-yr lag)"] = [accuracy_score(two.loc[te2, "crop"], pred2),

Takeaways

  • Beat a simple baseline first. Crop rotation is predictable, and the rotation rule alone sets a high bar. Comparing against it shows where the model actually adds value.
  • Check that "last season" is really last season. Lag features silently go wrong when a field has gaps in its history.
  • Split by time. Training on earlier seasons and testing on the latest one is how the model would be used for real.
  • More history helps most on the irregular fields. That's continuous corn, three-year rotations, and other fields where one season is ambiguous.
