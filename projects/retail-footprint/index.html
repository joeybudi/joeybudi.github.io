Retail footprint and disease-weather overlay

Python · pandas · GeoPandas · matplotlib  |  Download the notebook (.ipynb)

Two related questions from the same data:

  1. Footprint. For each ag retailer: how many growers buy each product group, how much they spend, how many acres they farm, and how many growers are active, lapsed, or long gone.
  2. Weather. Do growers in areas with disease-favorable weather (warm, humid, wet) actually buy more fungicide? Answering that needs a spatial join between grower locations and a gridded weather product.

About the data. The original combined point-of-sale transactions, a customer master table, program enrollment, and a commercial weather feed in Snowflake, with Apache Sedona for the spatial join in Spark. Everything here (retailers, growers, products, weather) is simulated with generic names. The joins, aggregations, and maps follow the original.

rng = np.random.default_rng(11)


def random_points(n, polys):
    shape = polys.union_all()
    minx, miny, maxx, maxy = shape.bounds
    pts = []
    while len(pts) < n:
        cand = gpd.points_from_xy(rng.uniform(minx, maxx, n), rng.uniform(miny, maxy, n))
        pts.extend([p for p in cand if shape.contains(p)])
    return gpd.GeoSeries(pts[:n], crs=4326)


# --- weather grid: smooth random fields -------------------------------------------------------
minx, miny, maxx, maxy = states.total_bounds
gx, gy = np.meshgrid(np.arange(minx, maxx, 0.25), np.arange(miny, maxy, 0.25))


def smooth_field(n_bumps, scale):
    z = np.zeros_like(gx)
    for _ in range(n_bumps):
        cx, cy = rng.uniform(minx, maxx), rng.uniform(miny, maxy)
        z += rng.uniform(0.5, 1) * np.exp(-((gx - cx) ** 2 + (gy - cy) ** 2) / (2 * scale ** 2))
    return (z - z.min()) / (z.max() - z.min())


wet = smooth_field(9, 1.6)
weather = pd.DataFrame({
    "lon": gx.ravel(), "lat": gy.ravel(),
    "precip_in": (0.2 + 2.6 * wet).ravel().round(2),
    "rh_pct": (58 + 32 * (0.7 * wet + 0.3 * smooth_field(6, 2.5))).ravel().round(1),
    "temp_f": (88 - 0.9 * (gy - miny) + 2 * rng.standard_normal(gx.shape)).ravel().round(1),
    "soil_moist_pct": (18 + 20 * wet).ravel().round(1),
})
grid_pts = gpd.GeoDataFrame(weather, geometry=gpd.points_from_xy(weather.lon, weather.lat), crs=4326)
weather = pd.DataFrame(grid_pts[grid_pts.within(states.union_all().buffer(0.3))].drop(columns="geometry"))

2. Product groups and grower status

The category hierarchy maps to the reporting groups the business uses. In the original this was a SQL CASE WHEN; here np.select keeps the same first-match-wins order.

For grower status, my first version labeled growers with no purchase in 6+ years as NEW, which reads as the opposite of what it means. Here they're long lapsed.

def product_group(df):
    cat = df.category
    return np.select(
        [cat.str.contains("NITROGEN"),
         cat.str.contains("HERBICIDE|INSECTICIDE|FUNGICIDE"),
         df.segment.eq("Seed"),
         cat.eq("ADJUVANT"),
         cat.isin(["MICRONUTRIENT", "SEED TREATMENT", "PLANT GROWTH REGULATOR"])],
        ["Nitrogen stabilizer", "Herbicide/Insecticide/Fungicide", "Seed", "Adjuvant", "Specialty"],
        default="Other")


items["product_group"] = product_group(items)

THIS_YEAR = 2026
growers["status"] = pd.cut(THIS_YEAR - growers.last_purchase_year, bins=[-1, 1, 5, 100],

5. Spatial join: growers × weather grid

Each grower gets the weather of the nearest grid cell. In Spark that was Sedona ST_Point plus a spatial join; in GeoPandas it's sjoin_nearest, done in an equal-area projection (EPSG:5070) so distances are in meters, not degrees.

A simple disease-favorable index (0-1) combines relative humidity and rainfall, the main drivers of foliar diseases like tar spot and gray leaf spot.

wx = gpd.GeoDataFrame(weather, geometry=gpd.points_from_xy(weather.lon, weather.lat), crs=4326).to_crs(5070)

Takeaways

  • Grain matters. Rolling transactions up to the grower first, then to the retailer, keeps distinct-grower counts correct. Counting rows would double-count growers who buy several items in a group.
  • Use a projected CRS for nearest joins. Distances in degrees are distorted; EPSG:5070 gives meters across the Midwest.
  • Line up the time periods. Sales and weather need to cover the same season before comparing them.
  • Turn it into a target list. The map and quintile chart show the pattern. The scatter of retailers turns it into a list someone can act on.
