Renewable fuel plants: from web maps to a GeoDataFrame

Python · requests · BeautifulSoup · GeoPandas  |  Download the notebook (.ipynb)  ·  GitHub repo

Where are the ethanol, biodiesel, and biomass plants, and which farm counties are close to them? Industry directories publish interactive plant maps, but no downloadable data. This notebook shows how I pulled that data, combined three plant types into one GeoDataFrame, and turned it into maps and a county-level "distance to demand" measure.

About the data. The original scraped three public plant directories. To avoid republishing someone else's dataset, the plants here are simulated with realistic regional patterns and capacities. The parsing code runs unchanged against a mock page built in the same format the real sites use.

1. Where the data hides

Many modern map pages are built with Next.js, which server-renders the page and ships the entire dataset as JSON inside a <script id="__NEXT_DATA__"> tag. Scraping the map then needs no browser automation and no HTML parsing of map markers. Find that one tag and read the JSON.

My first attempt drove a headless Chrome with Selenium and waited for markers to render. Reading __NEXT_DATA__ replaced it with one HTTP request per plant type.

def fetch_html(url):
    resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0 (research script; contact via site)"}, timeout=30)
    resp.raise_for_status()
    return resp.text


def parse_next_data(html, plant_type):
    """Pull the plant list out of a Next.js page's embedded JSON."""
    tag = BeautifulSoup(html, "html.parser").find("script", id="__NEXT_DATA__")
    if tag is None:
        raise ValueError("No __NEXT_DATA__ tag: the page layout may have changed")
    plants = json.loads(tag.string).get("props", {}).get("pageProps", {}).get("plants", [])
    df = pd.DataFrame(plants)
    df["plant_type"] = plant_type
    return df

Instead of hitting the live sites, I generate pages with the same structure: plants with name, city, state, country, coordinates, capacity, and status. A few non-US plants are included because the real directories list some, and they have to be filtered out.

by_state = states.set_index("STUSPS").geometry


def point_in(state):
    poly = by_state[state]
    minx, miny, maxx, maxy = poly.bounds
    while True:
        x, y = rng.uniform(minx, maxx), rng.uniform(miny, maxy)
        if poly.contains(gpd.points_from_xy([x], [y])[0]):
            return round(y, 5), round(x, 5)


def mock_page(plant_type):

    plants = []

            plants.append({"id": int(rng.integers(1e5, 1e6)), "name": f"{plant_type.title()} Plant {len(plants) + 1}",

3. Parse, combine, clean

All three plant types parse with the same function. Cleaning steps:

  • Drop non-US rows.
  • Unify capacity units. Ethanol and biodiesel report million gallons per year; biomass reports megawatts.
  • Build geometry with the right argument order. points_from_xy(x=longitude, y=latitude). My original ethanol cell passed latitude first, which silently put every ethanol plant somewhere in Antarctica. Checking that every point falls inside a US state catches that.
raw = pd.concat([parse_next_data(html, t) for t, html in pages.items()], ignore_index=True)
print(raw.groupby(["plant_type", "country"]).size().to_string())

plants = raw[raw.country == "United States"].copy()
plants["capacity"] = plants.capacity_mgy.fillna(plants.capacity_mw)
plants["unit"] = np.where(plants.capacity_mgy.notna(), "MGY", "MW")
plants = gpd.GeoDataFrame(plants.drop(columns=["capacity_mgy", "capacity_mw", "city"]),
                          geometry=gpd.points_from_xy(plants.longitude, plants.latitude), crs=4326)

inside = plants.sjoin(states[["STUSPS", "geometry"]], predicate="within")
assert len(inside) == len(plants), "some plants fall outside the US: check lat/lon order"

5. County access to ethanol demand

For a corn grower, a nearby ethanol plant is a buyer. For each county, sum the capacity of operating ethanol plants within 50 miles of its centroid. The buffer and intersection run in an equal-area projection (EPSG:5070), so 50 miles really is 50 miles everywhere.

MILES = 1609.34
cents = counties.to_crs(5070)[["GEOID", "NAME", "STUSPS", "geometry"]].copy()
cents["geometry"] = cents.centroid.buffer(50 * MILES)

6. Export

The combined layer is written as GeoJSON for GIS tools like ArcGIS and QGIS, and as a flat table for the warehouse.

import os

out = os.path.join(tempfile.mkdtemp(), "renewable_energy_plants.geojson")
plants.to_file(out, driver="GeoJSON")
print(f"{os.path.basename(out)}: {len(plants)} features, {os.path.getsize(out) / 1024:.0f} KB")

Takeaways

  • Look for the embedded JSON first. If a map page ships its data in __NEXT_DATA__, one request replaces a fragile headless-browser scraper.
  • One parser, many sources. A single function handles all three plant types, so adding a fourth is one line.
  • Assert the geography. A within-the-US check catches swapped coordinates immediately.
  • Project before buffering. Distance-based questions like "within 50 miles" need an equal-area or equidistant CRS.
